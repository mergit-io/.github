# .github

Organization-wide defaults for [**mergit-io**](https://github.com/mergit-io).

| File | Applies to |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The org landing page at github.com/mergit-io |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Every repo without its own copy |
| [`SECURITY.md`](SECURITY.md) | Every repo without its own copy |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default PR body |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Default issue forms |

**What Mergit is:** a trust and settlement layer for autonomous agent work — attested execution
receipts, outcome-contingent payment, and reputation measured as verified quality per unit cost.
The current source of truth is the paper in
[mergit-research](https://github.com/mergit-io/mergit-research); the project is pre-implementation.

A repo may override any of these by adding its own file of the same name.
